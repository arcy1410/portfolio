Featured case study

Curio: a learning feed people actually use

A swipeable feed of two-minute knowledge cards, each fact-checked by a second AI model before it ships. I ran the interviews, wrote the spec and the metrics framework, and built it with Claude Code. It earned an A, and Demo Day reviewers called it a production-ready MVP.

The data also showed where it breaks: a 25% leak before the first tap, and a North Star near zero because nothing brings users back yet. I wrote that up as the main finding.

Fold: warn users when a bank goes quiet
